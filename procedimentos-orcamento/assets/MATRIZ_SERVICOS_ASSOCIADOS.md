# Matriz de serviços associados

Lista de conferência contra omissões. Ao medir um elemento, conferir se a planilha tem item para cada serviço associado aplicável. O que faltar vai para o campo `sugestoes` do `levantamento.json` (serviço, motivo, local, fonte e, se medida, quantidade estimada), que vira a aba Sugestões; só entra na principal com pedido. A matriz não cria quantidade: cada serviço segue seu critério ([11](../references/11_criterios_padrao.md)) e precisa estar no projeto ou na especificação.

| Elemento no projeto | Serviços que costumam acompanhar |
|---|---|
| Parede de alvenaria nova | marcação e primeira fiada, alvenaria, vergas e contravergas, encunhamento, chapisco, emboço ou massa em cada face, revestimento ou pintura em cada face, rodapé, base ou fundação de parede no térreo, rasgos e enchimentos para instalações |
| Divisória de drywall nova | guias e montantes, chapas em cada face, isolamento (se especificado), tratamento de juntas, reforços para bancadas e suportes, pintura em cada face, rodapé, cantoneiras, base no térreo |
| Parede ou divisória demolida | demolição, retirada de revestimentos e de instalações embutidas, recomposição de piso, forro e paredes vizinhas, entulho e bota-fora |
| Vão novo em parede existente | demolição do trecho, verga, requadro, recomposição de revestimento, esquadria |
| Piso novo | retirada do existente (reforma), regularização ou contrapiso, impermeabilização em área molhada, piso, rodapé, soleiras, juntas, proteção, limpeza |
| Área molhada (banheiro, cozinha, serviço) | impermeabilização com subida, ralos e caimento, revestimento de parede, louças, metais, bancadas |
| Forro novo | estrutura e tirantes, forro, tabicas ou sancas, alçapões, recortes para luminárias e grelhas, pintura |
| Esquadria | contramarco, esquadria, vidro, ferragens, peitoril ou soleira, requadro, vedação, pintura (madeira ou ferro) |
| Bancada | tampo, saias, frontão, cuba, válvula e sifão, metais, suporte ou mão-francesa |
| Ponto elétrico | caixa, eletroduto, fiação, dispositivo, placa, circuito no quadro |
| Ponto hidrossanitário | tubulação, conexões, registro, ponto de espera, louça ou metal, teste |
| Luminária | ponto, fiação, luminária, lâmpada ou driver, recorte no forro |
| Cobertura | estrutura, telhas, cumeeiras, rufos, calhas, condutores, impermeabilização de lajes e platibandas |
| Escavação | escavação, escoramento, reaterro, compactação, bota-fora ou espalhamento |
| Concreto armado | formas, armadura, concreto, lançamento e adensamento, cura, desforma |
| Qualquer reforma | proteção do que é mantido, retirada e reinstalação, transporte interno, entulho, limpeza |
